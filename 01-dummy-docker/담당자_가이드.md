# Docker 담당자 가이드

모임 전에 이 더미 프로젝트에서 **Docker만** 처음부터 끝까지 한 번 직접 해봅니다.

Nginx, AWS는 하지 마세요. 그 단계는 다른 담당자의 숙제입니다.

---

## 당신이 만들어야 하는 것

```text
Next.js Dockerfile
NestJS Dockerfile
MySQL Container
docker-compose.yml
Docker Network
Environment Variable
Container 간 통신
```

완료 모습:

```text
Docker Network
├─ frontend :3000
├─ backend  :4000
└─ database :3306
```

---

## 작업 순서 체크리스트

1. [ ] `frontend/Dockerfile` 작성
2. [ ] `backend/Dockerfile` 작성
3. [ ] `.dockerignore` 작성 (frontend, backend 각각)
4. [ ] 프로젝트 루트에 `docker-compose.yml` 작성
5. [ ] compose 네트워크 이름 확인
6. [ ] backend 환경변수 `DB_HOST=database` 로 설정 (컨테이너 이름/서비스 이름 사용)
7. [ ] `docker compose up -d --build`
8. [ ] `docker compose ps` 로 3개 컨테이너 전부 실행 확인
9. [ ] 브라우저 `http://localhost:3000` 접속
10. [ ] `curl localhost:4000/health` 성공
11. [ ] 글 등록 후 DB까지 저장되는지 확인
12. [ ] `docker network inspect` 로 같은 네트워크에 있는지 확인

## 핵심 개념

로컬에서는 백엔드가 DB를 `localhost:3306`으로 찾습니다.

컨테이너 안에서는 `localhost`가 **그 컨테이너 자신**입니다.
그래서 backend 컨테이너는 MySQL을 `localhost`가 아니라 **서비스 이름**으로 찾아야 합니다.

```text
DB_HOST=database
```

`docker-compose.yml`의 서비스 이름이 `database`이면, 같은 Docker Network 안에서 `database:3306`으로 연결됩니다.

프론트엔드는 브라우저에서 실행되므로, 이 단계(Nginx 없음)에서는 브라우저가 `http://localhost:4000`으로 백엔드를 호출해도 됩니다. 그러려면 backend 포트 `4000:4000`을 호스트에 열어둬야 합니다.

## Dockerfile 힌트

둘 다 Node 20 이미지를 쓰면 됩니다.

예시 골격 (그대로 붙여넣기보다, 의미를 이해하고 작성하세요):

```dockerfile
FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build
EXPOSE 3000
CMD ["npm", "run", "start"]
```

백엔드는 포트 4000, 실행 명령은 `npm run start:prod`가 맞습니다.

`.dockerignore` 예:

```text
node_modules
.next
dist
.env
.git
```

## docker-compose.yml 힌트

서비스 3개:

```text
frontend
backend
database
```

database는 공식 이미지를 사용합니다.

```yaml
database:
  image: mysql:8.0
  environment:
    MYSQL_ROOT_PASSWORD: rootpass
    MYSQL_DATABASE: studyboard
    MYSQL_USER: study
    MYSQL_PASSWORD: study123
  ports:
    - "3306:3306"
  volumes:
    - mysql_data:/var/lib/mysql
    - ./database/init.sql:/docker-entrypoint-initdb.d/init.sql
  healthcheck:
    test: ["CMD", "mysqladmin", "ping", "-h", "localhost", "-uroot", "-prootpass"]
    interval: 5s
    timeout: 5s
    retries: 20
```

backend는 DB가 healthy 된 뒤에 켜는 것이 안전합니다.

```yaml
depends_on:
  database:
    condition: service_healthy
```

공통 네트워크:

```yaml
networks:
  app-network:
    driver: bridge
```

각 서비스에 `networks: [app-network]`를 넣습니다.

backend 환경변수 예:

```yaml
environment:
  DB_HOST: database
  DB_PORT: 3306
  DB_USER: study
  DB_PASSWORD: study123
  DB_NAME: studyboard
  PORT: 4000
```

frontend 환경변수 예 (Nginx 없는 현재 단계):

```yaml
environment:
  NEXT_PUBLIC_API_URL: http://localhost:4000
```

`NEXT_PUBLIC_*` 값은 이미지 빌드 시점에 들어가는 경우가 많습니다.
값이 반영되지 않으면 Dockerfile에서 `ARG` / `ENV`로 빌드 인자를 넘기거나, 브라우저가 `localhost:4000`을 쓰도록 기본값을 유지하세요.

## 실행 / 확인 명령어

프로젝트 루트(`01-dummy-docker`)에서:

```bash
docker compose up -d --build
docker compose ps
docker compose logs -f
```

개별 로그:

```bash
docker compose logs -f backend
docker compose logs -f frontend
docker compose logs -f database
```

헬스 체크:

```bash
curl http://localhost:4000/health
curl http://localhost:4000/api/posts
```

브라우저:

```text
http://localhost:3000
```

네트워크 확인:

```bash
docker network ls
docker network inspect 01-dummy-docker_app-network
```

네트워크 이름은 폴더명에 따라 달라질 수 있습니다. `docker network ls`에서 `app-network`가 들어간 이름을 찾으세요.

컨테이너 안에서 다른 컨테이너로 통신되는지 확인:

```bash
docker compose exec backend sh
# 컨테이너 안에서
wget -qO- http://database:3306 || true
# 또는
ping -c 1 database
exit
```

alpine 이미지에는 ping이 없을 수 있습니다. 없어도 backend 로그에 DB 연결 성공이 보이면 충분합니다.

## 자주 나오는 문제

| 증상 | 원인 | 해결 |
|---|---|---|
| backend가 DB 연결 실패 | `DB_HOST=localhost` | `DB_HOST=database` |
| frontend는 뜨는데 게시글 실패 | 브라우저가 4000에 못 감 | `4000:4000` 포트 공개 |
| mysql이 재시작할 때마다 이상함 | 볼륨/계정 불일치 | `docker compose down -v` 후 다시 up |
| 빌드가 느림 | context에 node_modules 포함 | `.dockerignore` 추가 |
| 3000이 이미 사용 중 | 로컬 `npm run dev`가 살아 있음 | 로컬 서버를 먼저 종료 |

완전 초기화:

```bash
docker compose down -v
docker compose up -d --build
```

## 완료 기준

아래가 전부 되면 Docker 사전 준비 완료입니다.

```bash
docker compose ps
curl http://localhost:4000/health
# 브라우저에서 http://localhost:3000 글 목록/등록 성공
docker network inspect <네트워크이름>
```

모임 당일에는 이 더미가 아니라 **실제 공동 프로젝트**에 같은 작업을 다시 적용합니다.
